# API Design Skill

An AI agent skill for designing RESTful and GraphQL APIs following industry best practices.

## What It Does

Guides you through the full API design lifecycle:

- **Resource modeling**: Identify entities, relationships, and operations
- **REST endpoint design**: Proper naming, HTTP methods, and response codes
- **Request/Response formatting**: JSON structure, error responses, pagination
- **Authentication**: JWT, OAuth 2.0, API keys
- **Versioning**: URL-based and header-based strategies
- **Documentation**: OpenAPI 3.0 spec generation
- **GraphQL alternative**: Schema and type definitions when REST isn't the right fit

## When to Use

- Creating a new API from scratch
- Refactoring or expanding existing endpoints
- Writing or reviewing API documentation (OpenAPI/Swagger)
- Deciding between REST and GraphQL
- Implementing pagination, filtering, sorting, or batch operations

## Compatibility

Works with Claude, ChatGPT, and Gemini agent platforms.
