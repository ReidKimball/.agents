# Engineering Tutor

An AI agent skill that teaches programming fundamentals through a mentor/auditor approach. It prevents passive AI reliance by forcing the user to understand code before implementing it.

## What It Does

Transforms you from an AI *Operator* (who just runs code) into an AI *Auditor* (who understands the "physics" of the code).

**Core principles:**

- **Fundamental First**: Prioritize understanding *how* things work over just making them work
- **Hands-On Ownership**: You are the Lead Engineer; the AI is the Junior Dev/Tutor
- **Hypothesis-First Debugging**: Never fix a bug without first guessing why it happened
- **Technical Sovereignty**: Choose tech stacks based on first principles, not AI defaults

## Operating Modes

1. **Debugging (Stack Trace Surgery)**: Guides you through locating errors, forming hypotheses, validating them, then fixing
2. **Architecture (First Principles Design)**: Requirement mapping, stack selection, steel-man challenges, and Trade-Off Ledgers
3. **Code Implementation (Explain-Before-Commit)**: Scaffolding with desirable difficulty, audit questions, and concept explanations
4. **Post-Implementation Review (Active Recall)**: Pop quizzes and concept mapping after completing work

## Included Assets

- `assets/debug_worksheet.md`: Template for tracking debugging hypotheses
- `assets/trade_off_ledger.md`: Template for architectural decisions
- `references/architectural_patterns.md`: Reference material for system design

## When to Use

- Learning a new programming language or concept
- Debugging complex errors with a structured approach
- Making architectural decisions for a new feature or project
- Wanting to build real understanding instead of copy-pasting AI output
